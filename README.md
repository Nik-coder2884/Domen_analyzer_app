# Консольный WHOIS-сборщик данных (Domen Analyzer)

Утилита на Python для получения и анализа информации о любом доменном имени. 
Приложение запрашивает данные через WHOIS, извлекает 9 ключевых параметров и выводит их в виде аккуратного отчета в терминале.

## Особенности
-   **Поддержка кириллицы:** корректно работает с доменами в зонах `.рф` и другими IDN (автоматическое преобразование в Punycode).
-   **Надежность:** двойная система запросов (библиотека + HTTP-резерв) позволяет получать данные, даже если сетевые порты заблокированы.
-   **Обработка ошибок:** если WHOIS-сервер скрывает данные (например, ФИО владельца в зоне `.рф`), приложение выводит «нет данных» вместо ошибки.
-   **Валидация ввода:** проверка домена на запрещенные символы, длину и корректность структуры.

## Архитектура приложения
Приложение состоит из четырех независимых модулей:

1.  **`api_client.py`** — Точка входа для сети. Запрашивает сырые данные через библиотеку `python-whois` или HTTP-запрос.
2.  **`data_processor.py`** — Двигатель логики. Извлекает из сырого ответа 9 целевых полей и нормализует их (приводит даты к формату ГГГГ-ММ-ДД, объединяет списки).
3.  **`report.py`** — Визуализатор. Формирует и выводит в терминал читаемый текстовый отчет с выравниванием.
4.  **`main.py`** — Точка входа. Запрашивает имя у пользователя, координирует работу модулей и обрабатывает ошибки.

## Установка и запуск

### 1. Системные требования
-   Python 3.8 или выше.

### 2. Установка библиотек
Откройте терминал в папке с проектом и выполните команду:
```bash
pip install python-whois requests

(Библиотека idna не требуется, так как приложение использует встроенные средства Python для работы с кириллицей).

3. Запуск

Запустите приложение через терминал:

python main.py

4. Пример работы

==================================================
          WHOIS-КОНСОЛЬНЫЙ СБОРЩИК ДАННЫХ
==================================================
Введите доменное имя (например, yandex.ru или яндекс.рф): яндекс.рф

Домен преобразован в Punycode для запроса: xn--d1acpjx3f.xn--p1ai

Идет запрос данных для: xn--d1acpjx3f.xn--p1ai...
Выполняется запрос через библиотеку python-whois...

==================================================
               ОТЧЕТ ПО ДОМЕНУ
==================================================
Доменное имя:                xn--d1acpjx3f.xn--p1ai
Владелец или организация:    (нет данных)
Регистратор:                 REGRU-RU
Дата регистрации:            1997-09-24
Дата истечения:              2025-10-31
Дата последнего обновления:  2024-10-01
Серверы имён:                ns1.yandex.ru, ns2.yandex.ru
Статус домена:               REGISTERED, DELEGATED, VERIFIED
Страна регистранта:          RU
==================================================
Извлекаемые данные (9 полей)

Приложение автоматически находит и выводит следующие параметры:

Поле в отчете	Описание
Доменное имя	Адрес сайта (в Punycode для кириллицы).
Владелец или организация	Кто зарегистрировал домен (часто скрыт в зонах .RU/.РФ).
Регистратор	Аккредитованный регистратор (например, REGRU-RU).
Дата регистрации	Когда домен был впервые создан.
Дата истечения	Когда закончится оплаченный период.
Дата последнего обновления	Когда менялись данные домена.
Серверы имён	DNS-серверы, обслуживающие домен.
Статус домена	Текущее состояние (активен, заблокирован и т.д.).
Страна регистранта	Код страны владельца (например, RU, US).
